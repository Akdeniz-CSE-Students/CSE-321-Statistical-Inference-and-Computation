## Adding a paper

File it under the academic year it was sat: `exams/past/<YYYY>-<YYYY>/`. Note the
group letter if the paper has one — this course runs multiple versions. If it is
somebody's answered paper rather than a blank one, it belongs in
`terms/<year>-<term>/` instead.
